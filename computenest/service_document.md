# Legado 开源阅读服务端与 Web 客户端

## 1. 服务概述

**Legado Server** 是将知名开源阅读应用（Legado / 阅读 3.0）重构为纯 JVM 后端与现代化 React 19 Web 客户端的无头（Headless）阅读服务。

通过阿里云计算巢一键部署，您可以在几分钟内拥有一个专属的私有化云端书库与跨平台阅读器：
* **彻底跨平台**：无需安装客户端，随时随地在手机浏览器、电脑浏览器、平板或墨水屏设备上畅快阅读。
* **生态深度兼容**：原生兼容 Legado 丰富的开源书源生态，支持书源规则沙箱解析（Jsoup + JsonPath + Rhino JS）、书源导入/导出与订阅自动同步。
* **极致性能与离线持久化**：底层采用弹性容器实例（ECI）与文件存储（NAS），SQLite 数据库、书架进度与书籍封面持久化安全隔离，支持秒级冷启动与弹性变配。

## 3. 部署架构

本服务采用云原生高可用架构部署：
1. **网络入口**：弹性公网 IP（EIP）+ 安全组（开放 8080 端口），提供 Web 端访问通道。
2. **计算核心**：阿里云弹性容器实例（ECI），运行 Legado Server（Ktor + Kotlin JVM + React 19 前端）。
3. **持久存储**：阿里云通用型文件存储（NAS）通过 NFS 协议挂载至容器 `/data` 目录，确保书架、阅读进度与封面永久保存。

## 5. 快速上手使用指引

### 5.1 访问服务
服务实例部署成功后，在计算巢服务实例详情页中查看 **`WebUrl`**（格式为 `http://<您的公网IP>:8080`），点击即可进入 Web 阅读器界面。

### 5.2 管理员登录
1. 打开 Web 页面右上角或提示弹窗中的 **「登录」**。
2. 输入您在部署时设置的 **管理员初始密码** 即可登录管理控制台。

### 5.3 导入书源
1. 点击导航栏中的 **「书源管理」**。
2. 点击 **「导入网络书源」** 或 **「本地导入」**，粘贴 Legado 常用书源链接（JSON 格式）。
3. 导入后即可在搜索栏中全网并发检索书籍并一键加入书架。

## 6. 常见问题与运维

### Q1: 部署完成后提示 `HTTP ERROR 502` 或无法连接？
* 请确认访问链接是否包含了端口号 `:8080`（例如 `http://1.2.3.4:8080`）。直接访问 `http://1.2.3.4` 默认走 80 端口将无法打开。

### Q2: 如何重置管理员密码？
* 若遗忘密码，可在计算巢控制台使用运维命令或通过容器执行密码重置命令。

### Q3: 如何调整配置（变配）？
* 在计算巢控制台的 **「服务实例详情」** 页面，点击顶部 **「变配」** 按钮，即可随时在线弹性升降 CPU、内存或公网带宽。
