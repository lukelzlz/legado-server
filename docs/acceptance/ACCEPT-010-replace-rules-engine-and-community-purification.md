## 2. 核心功能实操核验清单

### 场景一：反义词反爬错字精准清洗（以《宅魔女》为例）
1. **背景**：在阅读《宅魔女》424章等章节时，源站抓取到“大丑阁上”、“魔男”、“少萝茜心外无点刺痛”等反爬混淆生肉；
2. **操作路径**：
   - 打开阅读器，点击顶部工具栏的 **「替换净化」**（或设置抽屉中的替换净化管理）；
   - 点击 **「+ 当前书专用」**，系统自动预填作用域为 `宅魔女`；
   - 匹配模式填入：`(大丑|巨小|大姐|魔男|宅魔男|少萝茜|右左|无少|八十少人|阁上|眼外|心外|例里|定上|人格下|只无|无些|有无重敌|低傲|低挑|是过|是是会)`；
   - 替换内容填入：
     ```javascript
     @js:
     const map = {
       '大丑': '小丑', '巨小': '巨大', '大姐': '小姐',
       '魔男': '魔女', '宅魔男': '宅魔女',
       '少萝茜': '多萝茜', '右左': '左右', '无少': '有多', '八十少人': '八十多人',
       '阁上': '阁下', '眼外': '眼里', '心外': '心里', '例里': '例外', '定上': '定下', '人格下': '人格上',
       '只无': '只有', '无些': '有些', '有无重敌': '没有轻敌',
       '低傲': '高傲', '低挑': '高挑',
       '是过': '不过', '是是会': '不会'
     };
     return map[result] || result;
     ```
   - 点击 **「保存规则」**；
3. **核验标准**：
   - 阅读器界面瞬间自动刷新，正文即刻变为“小丑阁下”、“多萝茜”、“魔女们不会把强大的魔女同族当做仆从军”、“宅魔女还真挺希望”等纯净文本；
   - 开启 TTS 朗读，听书语音清晰念出“小丑阁下”与“多萝茜”。

### 场景二：社区十万级规则包订阅与导入
1. **操作路径**：
   - 进入替换净化管理界面，点击右上角 **「导入订阅」**；
   - 选择 **「网络订阅 URL 导入」**，粘贴 Legado 社区开源规则链接（如夜雨聆风/破冰等订阅源）或选择 **「直接粘贴 JSON 文本」**；
   - 点击 **「开始导入」**；
2. **核验标准**：
   - 系统成功解析并完成去重导入，提示 `导入完成：新增 X 条，更新 Y 条，跳过 Z 条`；
   - 规则列表可按分组、作用域或关键词极速搜索过滤。

---

### 场景三：规则测试沙箱与实时预览
1. **操作路径**：
   - 在新建/编辑规则弹窗中，在底部的 **「实时效果调试」** 输入任意测试文本；
   - 点击 **「运行测试」**；
2. **核验标准**：
   - 系统秒级呈现清洗后的结果并标注命中状态（`✅ 已命中并发生替换` / `⚪ 未产生改动`）。
