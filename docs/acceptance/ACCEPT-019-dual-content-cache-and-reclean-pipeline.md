# 验收手册 ACCEPT-019: 双副本正文缓存与规则重洗流水线

## 1. 交付目标概述

实现正文缓存「书源提取原文 (`raw_content`, `raw_title`)」与「展示清洗副本 (`content`, `title`)」双副本存储机制。用户在更新/启用/停用替换规则后，可在书架卡片管理菜单（三个点）或批量操作栏中一键触发重新清洗，无需耗流重新下载。

## 3. 手工 UI 实操验收步骤

### 场景 A：书架卡片三点菜单触发单书重新清洗
1. 打开书架页面，选择任意一本已有离线缓存的网络书籍或本地书籍。
2. 点击书架卡片右下角的三个点菜单按钮（`...`）。
3. 在弹出的书籍管理面板中，可以看到新增的 **「重新应用净化规则」** 按钮。
4. 点击该按钮，面板显示“正在重新清洗正文...”，随后弹出成功提示（如“《xxx》重新清洗完成，共处理 N 章”）。
5. 进入阅读器，即可看到最新规则清洗后的正文。

### 场景 B：规则误杀与还原验证
1. 在替换规则管理页面（`#rules`）中添加一条将特定词替换掉的规则（例如将正文中的某个主角名替换）。
2. 在书架对应书籍上点击「重新应用净化规则」，进入阅读器确认该名字已被替换。
3. 停用或删除该规则。
4. 再次在书架对应书籍上点击「重新应用净化规则」，进入阅读器确认正文已基于 `raw_content` 完美还原。

### 场景 C：书架批量重洗
1. 点击书架顶部的「批量管理」按钮。
2. 勾选多本已缓存的书籍。
3. 点击底部浮动工具栏中的「重洗规则」按钮。
4. 观察 Toast 提示完成总处理章节数。
