# 验收手册 ACCEPT-020: 本地导入书籍联网搜索与元数据补全

## 1. 交付目标概述

支持在「编辑书籍信息」弹窗内部直接发起全网书源流式搜索，搜索命中同名书籍后，支持一键将匹配项的高清封面、作者名填充至表单，并将命中书源沉淀至书籍的 `alternate_sources`（备选书源）中落库存储。本地书籍正文与分章目录保持 100% 本地独立，不被外部书源正文覆盖破坏。

---

在终端执行以下最短验证命令，确保全套前后端测试 100% 通过：

## 3. 手工 UI 实操验收步骤

### 场景 A：本地书籍联网搜索并一键选用封面与作者 (Happy Path)
1. 启动服务（通过 Docker 或本地 `./gradlew :server:run`），浏览器登录 `http://127.0.0.1:8080/#shelf`。
2. 找到任意一本本地导入的书籍（或点击「导入本地」导入一本仅有书名、缺少作者与封面的 TXT 小说，如《变成魔女，但是她们都想跟我恋爱》）。
3. 点击书籍卡片右下角的 `...` 菜单，选择 **「编辑书籍信息」**。
4. 弹窗顶部呈现 **「🔍 联网搜索补全信息」** 按钮（对于未设置封面与作者的本地书籍，显示高亮“推荐”徽标）。
5. 点击该按钮，面板平滑展开，默认填入当前书名原样作为搜索词，并自动发起流式搜索。
6. 观察到实时搜索进度（如“已检索 X/Y 个书源 · 共 N 条结果”），下方流式呈现包含封面、书名、作者、书源名称与简介片段的候选书籍卡片。
7. 在最满意的一条候选卡片上点击 **「选用」**：
   - 按钮即刻变为绿底高亮「已选用」；
   - 弹窗左侧的“封面预览”立刻刷新为所选网络封面；
   - 表单中的“作者”输入框自动填充候选小说的作者名；
   - 表单下方的“从备选书源选择封面”网格即刻展示本次检索出的候选封面。
8. 点击弹窗底部的 **「保存修改」**：
   - 服务端自动拉取该网络封面并持久化缓存到服务器本地，书籍信息与备选书源成功落库；
   - 书架上的该书卡片立刻换上精美封面并展示正确的作者名。

### 场景 B：搜索关键词手动微调
1. 打开带有特殊文件名后缀的本地书籍（例如《某某小说[精校全本].txt》）的「编辑书籍信息」弹窗。
2. 展开联网搜索补全面板，在搜索框中将多余的 `[精校全本]` 后缀手动删除。
3. 点击「搜索」按钮（或按下回车），系统以修改后的关键词重新发起多书源检索。
4. 正确获得精准匹配的同名小说结果并可顺利选用。

### 场景 C：本地正文与阅读连续性检验 (Preserve Local Content)
1. 在完成联网补全并保存后，点击该本地书籍卡片进入阅读器。
2. 确认章节目录、正文内容、排版均完好无损，严格从本地文件加载。
3. 开启 Edge-TTS 朗读，确认本地正文连播无任何异常。
