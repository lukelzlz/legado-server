## 1. 交付目标概述

1. **书源分组（在「书源」页面统一管理）**：「分组管理」是**独立按钮**（不再藏在批量管理里），面板内可
   查看分组（名字 + 组内总数 + 已启用数）、**重命名**、**删除**（只解绑，不删书源），以及**批量勾选书源 → 加入某个分组 / 移出分组 / 新建分组并加入**。
2. **按分组搜书（在「书库」页面）**：搜索栏**下面**一排「搜索范围」选项卡 = `全部书源` + 各书源分组（显示已启用源数）+ `未分组`；**「全部书源」永远是第一项且是默认项**。
3. **导入语义（两条路径分开）**：
   - **导入书源文件 / 订阅更新** → **不自动分组**：新源一律「未分组」，分组只能在「分组管理」里手动整理（重复导入也**不会**清掉你手工分好的组）；
   - **导入手机备份** → 按备份里的分组落库，导入提示含「含书源分组 N 个」。

## 3. 手工 UI 验收步骤

### 场景 A：按书源分组搜书（书库页 · Happy Path）
1. 启动服务并登录，停在默认的 **「书库」** 页（`http://<你的地址>/`）。
2. 在「输入书名或作者」**搜索栏的正下方**，应看到一排「搜索范围」选项卡：
   - 第一项是 **`全部书源`**，并且**默认就是选中态**（高亮圆圈）；
   - 其后是各个书源分组（标签上带一个数字 = 该分组**已启用**书源数）；
   - 最后是 `未分组`；右侧还有「指定单个书源 / 不限」下拉。
3. 点某个分组（例如 `大灰狼聚合`）：
   - 该分组变成**唯一**高亮项；`全部书源` 仍在但取消高亮；
   - 输入关键词回车，搜索进度文案里的「已检查 X / Y 个书源」总数 = **该分组的已启用源数**（不再跑全部源）。
4. 点回 **`全部书源`**：范围立刻复位，再搜即为全量已启用书源。

### 场景 B：分组管理（书源页 · 独立按钮）
1. 顶栏进入 **「书源」** 页，点顶部 **「分组管理」** 按钮（与「体检」「批量管理」并列）。
2. 面板头部右侧有 **「分组 / 书源 / 未分组」三个数字块**（未分组 > 0 时高亮）；上半部「已有分组」：每行是「首字标记 · 分组名 · N 个 · 启用 M」，右侧有 **「重命名」「删除」**（图标按钮，鼠标移上去才浮出底色）：
   - **重命名**：弹出输入框，确认后组内**所有书源**一次性改名（改成已存在的名字即合并）；
   - **删除**：确认文案明确写「组内 N 个书源不会被删除，只会变成『未分组』」；确认后分组消失、书源仍在，并可在「未分组」里找到。
3. 面板下半部是浅底工作台「把书源加入分组」：
   - 勾选若干书源（可按名称/地址/分组筛选，支持全选 / 全不选 / 反选，**未分组的源排在最前**）；
   - 「目标分组」选一个已有分组 → 点 **「加入分组」**；或选 **「+ 新建分组…」** 并填名字 → 点「加入分组」即创建该分组并把勾选的书源放进去；
   - 点 **「移出分组」** 可把勾选的书源一次性变成未分组。
   - 注意：**不勾选任何书源就点「加入分组」会提示先勾选**；未选目标分组/未填新名字也会提示，**不会**自动猜一个分组。
4. 回到「批量管理」：工具栏里**已没有**分组相关动作（分组管理只在这一个入口）。

### 场景 C：导入语义（书源文件 vs 手机备份）
1. **导入书源文件**（书源页「导入 JSON」，或新建订阅并更新）：
   - 若书源文件里带 `bookSourceGroup`，**不会**自动分组；提示会写明「导入完成：新增 N 个…（导入的书源默认未分组，可在「分组管理」里归类）」；
   - 在「分组管理」里手工分好组后，**再导入同一个书源文件，你分的组不会被清空**。
2. **导入手机备份**（「文件」页 → 该 `.zip` → 导入）：
   - 分组**照备份来**，成功提示形如 `导入完成：书源 N（含书源分组 1 个），…`；
   - 回「书库」页，搜索栏下方应出现备份里的分组选项卡；在「分组管理」里也能看到它。

## 4. 关键校验点（勾选清单）

- [ ] 书库页搜索栏**下面**有搜索范围选项卡，**第一项是「全部书源」且默认选中**
- [ ] 选中分组后搜索进度只统计该分组（`已检查 X / 该组已启用源数`）
- [ ] 点回「全部书源」范围复位，无残留分组
- [ ] 书源页顶部有**独立的「分组管理」按钮**（不在批量管理里）
- [ ] 面板内「重命名 / 删除」可用；改名整组生效
- [ ] 删除分组**不删除书源**（组内书源变为未分组且仍可搜到）
- [ ] 面板内可**批量勾选书源 → 加入指定分组**（也可新建分组、移出分组）；不勾选/不选目标分组时会提示而不是自动猜
- [ ] 批量管理工具栏里**不再有**分组相关动作
- [ ] **导入书源文件不自动分组**（提示写明默认未分组）；已手工分好的组**不会被再次导入清空**
- [ ] 导入手机备份后提示含「含书源分组 N 个」，且书库页出现对应分组选项卡
