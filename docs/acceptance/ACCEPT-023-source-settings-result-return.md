## 2. 验收步骤（点哪里、看什么）

| # | 操作 | 期望现象 |
| :--- | :--- | :--- |
| 1 | 浏览器打开 `http://127.0.0.1:8080` → 登录 → 左侧「书源」 | 出现「书源管理」，左侧能看到 `🍅大灰狼聚合5.9.26(vip完全版)` |
| 2 | 点该书源 → 右上「登录」 | 弹出 `登录 大灰狼融合VIP5.0`，能看到邮箱/密码/`⚙️ 书源设置中心` 等按钮 |
| 3 | 点 `⚙️ 书源设置中心` | 弹窗内出现**内置浏览器**并加载「书源设置」页（线路/搜索/听书音色/段评气泡/阅读功能） |
| 4 | 顶部提示 | 出现「设置中心已在内置浏览器中打开，改动会自动保存」，**不应**出现「未读取到设置结果」 |

| 7 | 点右上「✓ 登录完成」 | 内置浏览器关闭，提示登录态/Cookie 数；**不应**再弹出 `data:` 开头的空白新标签 |

| 9 | `Ctrl+C` 停服后重新 `.\start-server.cmd`，再进设置中心 | 设置**仍然是听书**（持久化生效） |
