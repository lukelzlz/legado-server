# ACCEPT-024: 自定义 HTTP 朗读引擎与 Legado 规范管理互通验收手册 (Issue #25)

## 1. 验证目标
验证在听书朗读中完整支持自定义 HTTP 朗读引擎体系：
1. 在听书设置中可以切换内置 Edge-TTS、系统本地 Web Speech、以及用户自定义的 HTTP 朗读源。
2. 在听书设置中点击「TTS 管理」可打开专门的朗读引擎管理中心（支持新建、编辑、删除、单项试听、单个导出、全部导出、文件/文本导入）。
3. 支持导入 Legado 手机端导出的 `httpTTS.json` 规则并无缝互通。
4. 听书朗读时能够正确解析 `url,{options}` 语法与 `{{speakText}}`、`{{speakSpeed}}` 及 `{{java.encodeURI(...)}}` 等宏变量。

---

## 2. 自动化测试套件基准

在终端执行全量回归命令：
```sh
npm --prefix web run check && npx tsx web/test/run-all.ts && ./gradlew :server:test
```
预期结果：
- 前端 TypeScript 类型检查通过（无报错）
- 前端测试套件 180 个用例全部通过（0 失败）
- 后端 Gradle 测试通过（含 `HttpTtsTest` 的 CRUD、Legado 导入、沙箱模板求值、Mock 服务端请求、REST 路由端点）

## 3. Web 界面手动实操验收步骤

### 场景一：打开 TTS 管理中心与导入 Legado 规则
1. 打开 Web 阅读器，点击底栏或顶栏的「朗读」按钮，进入听书控制栏。
2. 点击控制栏上的齿轮「设置」按钮，弹出「听书朗读设置」弹窗。
3. 查看「朗读引擎」区域右上角新增的 **「⚙️ TTS 管理」** 按钮，点击它。
4. 此时弹出 **「自定义 HTTP 朗读引擎管理」** 面板。
5. 点击顶部的 **「导入 httpTTS」** 按钮：
   - 方式一：选择本地下载的 `httpTTS.json` 文件（例如从开源阅读手机端导出的规则文件）。
   - 方式二：直接在文本框内粘贴 Legado 规则 JSON，点击「确认导入」。
6. 列表立刻展示导入的各条朗读引擎卡片（如“1.百度”、“2.阿里云语音”等），并标注格式标签（如 `WAV`, `MPEG`）。

### 场景二：单项试听与编辑
1. 在列表中找到刚刚导入或新建的某个 HTTP TTS 引擎，点击卡片上的 **「试听」** 按钮。
2. 按钮切换为“合成中...”，合成成功后自动播放试听音频，并在顶部显示“合成成功，正在试听发音”。
3. 点击卡片上的 **「编辑」**（铅笔图标）按钮，打开编辑弹窗：
   - 查看名称、请求 URL（包含 `url,{options}` 语法与 `{{speakText}}` 等占位符）、音频类型等字段。
   - 点击底部的「测试发音」，可实时试听修改后的配置。
   - 修改后点击「保存」，列表自动更新。

### 场景三：在阅读器朗读设置中选用并听书
1. 在管理列表中点击卡片上的 **「使用」**，或关闭管理弹窗返回「听书朗读设置」弹窗。
2. 在「朗读引擎」中点击选中 **「自定义 HTTP 朗读」**。
3. 下方出现「选择 HTTP 音源」下拉框，选中已配置好的 HTTP 引擎（如“百度语音”）。
4. 点击「完成」关闭设置，点击听书控制栏的 **「播放」** 按钮。
5. 系统自动根据选中的自定义 HTTP 引擎合成正文分句，连续流畅朗读！

### 场景四：全部导出与生态互通
1. 再次进入「TTS 管理」面板。
2. 点击顶部工具栏的 **「全部导出」** 按钮。
3. 浏览器自动触发下载 `httpTTS.json` 文件。
4. 将该文件发送到手机端开源阅读（Legado）APP，导入 HTTP TTS，可 100% 成功识别入库，验证双向互通成功。
