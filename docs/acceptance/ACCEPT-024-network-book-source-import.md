## 0. 这次新增了什么

| 之前 | 现在 |
| :--- | :--- |
| 只能上传本地 JSON 文件，或配「订阅」定时拉取 | 书源页多一个「**网络导入**」按钮，粘贴一个 URL 即可导入 |
| 书源「更新书源」页的线路按钮 `yuedu://…` 点了**没反应**，书源永远更新不了 | 点线路**弹出预览弹窗**并自动拉取，确认后完成更新 |
| 无法在导入前看到「会新增什么、会更新什么」 | 弹窗逐条标出 **新增 / 更新 / 不可导入**（不可导入附原因且勾不上） |
| 导入 JSON 一律落「未分组」 | 弹窗里**可选**目标分组；不选则保持原分组不变 |

## 1. 一键启动（源码模式，数据落在同级 `data/`）

```powershell
cd <项目根目录>          # 即 start-server.cmd 所在目录
```

## 2. 验收步骤（点哪里、看什么）

### 2.1 直接网络导入（书源页入口）

| # | 操作 | 期望现象 |
| :--- | :--- | :--- |
| 1 | 打开 `http://127.0.0.1:8080` → 登录 → 左侧「书源」 | 「导入 JSON」**正下方**出现「**网络导入**」按钮，图标是**云 + 下箭头** |
| 2 | 点「网络导入」 | 弹出「导入书源」面板：地址输入框 + 「拉取」；右上「自定义源分组」与 `⋮`；底部「取消 / 确认」，**确认按钮此时是灰的** |
| 3 | 粘贴 `https://shuyuan.nyasama.net/shuyuan/e15ba957b1486ec2f2bc7e0bdb0964ea.json` → 点「拉取」 | 约 1 秒后列出 **4 条**书源，每条带「**新增**」标签，默认全部勾选，计数显示「取消全选（4/4）」 |
| 4 | 点 `⋮` → 试「取消全选」「全选」「反选」 | 勾选与 `(n/4)` 计数实时同步；「确认」在 0 选中时点一下应提示「请先勾选要导入的书源」 |
| 5 | 点「确认」 | 提示「导入完成：新增 N 个，更新 M 个」；弹窗关闭；左侧书源列表出现新源 |
| 6 | **再拉一次同一个地址** | 这 4 条这次显示「**更新**」标签（而不是「新增」），确认后**不会产生重复书源** |
| 7 | 粘贴 `https://shuyuan-api.yiove.com/import/book-source-collection/b8fd3e19-08dd-4f05-a7b4-d6cc909de8e6` → 拉取 | 列出 **383 条**（列表可滚动）；确认后批量导入，提示如实回报新增/更新数 |

### 2.2 分组（「自定义源分组」）

| # | 操作 | 期望现象 |
| :--- | :--- | :--- |
| 8 | 点右上「自定义源分组」 | 出现分组选择：`不分组` / 已有分组 / `新建分组…`，并提示「不选则保持原分组不变，新书源落未分组」 |
| 9 | 选「新建分组…」→ 输入 `网络导入测试` → 确认导入 | 本次导入的书源全部归入「网络导入测试」（回书源页分组栏可见） |
| 10 | 再导入一个**已有分组**的源，且**不选**分组 | 该源的分组**保持原样**，不会被清空 |

### 2.3 内置浏览器「更新书源」线路（核心修复）

| # | 操作 | 期望现象 |
| :--- | :--- | :--- |
| 11 | 书源页点「大灰狼聚合」→「登录」→ 点 `❇️ 更新书源` | 内置浏览器打开「大灰狼书源更新」页（显示当前版本 / 最新版本 / 线路按钮） |
| 12 | 点「**主线路**」（或任一备用线路） | **弹出与 2.1 完全相同的「导入书源」面板**，地址已自动填好并**自动拉取**，条目带「更新」标签 |
| 13 | 点「确认」 | 提示导入完成；该源被**更新**（不是新增一条重复源） |
| 14 | 关掉登录弹窗再重开 → 点「登录」 | 书源名/版本为更新后的版本 |

### 2.4 主题跟随

| # | 操作 | 期望现象 |
| :--- | :--- | :--- |
| 15 | 依次切到 **浅色 / 羊皮纸 / 深色** 主题，各打开一次导入弹窗 | 弹窗底色、文字、描边、按钮全部跟随主题；**不出现**透光背景或隐形黑字 |

### 2.5 异常如实告知（四语）

| # | 操作 | 期望现象 |
| :--- | :--- | :--- |
| 16 | 地址留空直接点「拉取」 | 提示「请填写书源地址」 |
| 17 | 填 `ftp://example.com/a.json` | 提示「仅支持 HTTP(S) 地址」 |
| 18 | 填 `http://127.0.0.1:8080/a.json` | 提示「拒绝访问内网或本机地址」（防 SSRF） |
| 19 | 填一个返回 HTML 的普通网址 | 提示「该地址返回的内容不是有效的书源 JSON」 |
| 20 | 切到 **English** 后重复 18 | 提示为英文（`... is blocked`），**不出现中文** |
| 21 | 拉取后**放置超过 10 分钟**再点「确认」 | 提示「预览已过期，请重新拉取」（而不是静默失败） |

## 4. 回归红线（确认没被碰坏）

| 场景 | 期望 |
| :--- | :--- |
| 「导入 JSON」上传本地文件 | 行为与之前**完全一致**（仍不自动分组） |
| 「订阅」定时拉取 | 行为不变；解析改走共享的 `SourceCodec.parseSourceList`，包装形态兼容性只增不减 |
| 书源登录弹窗其它按钮（检测登录 / 番茄登录 / 切换服务器…） | 不受影响 |
| 书源设置中心（上一版修复） | 仍能自动落库、仍不乱开 `data:` 新窗口 |

## 5. 已知未覆盖（本次不在范围内）

- **`location.href` 直跳 `yuedu://` 拦不住**：语言层面改不了 `location` 赋值。
  当前「更新书源」页用的是静态 `<a href>`，所以可用；若将来改成 `location.href` 形式需重新评估。
- **上游返回 404 等错误时保留原始状态码文案**（如「上游返回 HTTP 404」），该条不参与四语翻译。
- **`/api/sources/import` 的整包体积上限仍缺失**（既有缺口，按决定留待后续单独立项）。
