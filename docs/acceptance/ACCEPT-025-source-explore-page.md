# 验收手册 ACCEPT-025: 书源发现页（Explore）与多维分类浏览体系

## 1. 目标与验收范围
针对 [Issue #24](https://github.com/lukelzlz/legado-server/issues/24)，为 Legado Server 提供完整的“发现”能力：
1. **顶栏「发现」选项卡**：与书架、书库、书源并列，支持四语切换。
2. **书源与分类解析**：自动过滤并展示支持发现页的书源，兼容多行纯文本（`::`/`&&`）、JSON 数组及 `<js>` 动态沙箱求值三种语法。
3. **书籍列表与规则回退**：展示推荐书籍（封面、书名、作者、简介），优先采用 `ruleExplore`，未配置时无感回退至 `ruleSearch`。
4. **一键加架与秒开阅读**：支持单书即时加架（自动查重与状态切换）和“立即阅读”直接秒开沉浸式阅读器。

## 3. 手工与 UI 验收步骤

1. **进入「发现」页**：
   - 登录系统后，观察顶栏导航，确认新增「发现」选项卡（位于“书库”与“书架”之间）。
   - 点击「发现」，页面平滑切换至发现视图。
2. **选择书源与查看分类**：
   - 左侧展示支持发现页的书源列表，支持在筛选框输入关键词快速查找书源。
   - 选中某个书源（如聚合源或精选源），左侧分类区域即刻展示该书源提供的分类、榜单（如“周热榜”、“月票榜”、“玄幻”、“都市”等）。
3. **浏览书籍列表与加载更多**：
   - 点击某个分类标签，右侧主视口即刻展示书籍卡片网格。
   - 观察卡片展示的书名、作者、简介摘要与封面图。
   - 滚动到底部，点击「加载更多」，观察系统顺畅获取第 2 页并拼接到下方。
4. **一键加入书架**：
   - 在书籍卡片上点击「加入书架」，系统异步请求详情并加入书架，按钮状态变为「已在书架」，并弹出加入成功 Toast 提示。
   - 切换至「书架」选项卡，确认该书已出现在书架中。
5. **立即开读**：
   - 在卡片上点击「立即阅读」，阅读器秒开进入正文阅读界面。
6. **多语言切换**：
   - 在顶栏切换语言（简体中文、繁体中文、English、日本語），确认发现页面的标题、按钮与提示文本均完美本地化，无漏翻或硬编码。
