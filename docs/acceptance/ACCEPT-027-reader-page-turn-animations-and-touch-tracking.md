# 验收手册：阅读器全量翻页动画体系与高帧率触控跟手引擎 (ACCEPT-027)

## 1. 业务背景与改动概述
对齐 Legado 原生 Android 端的翻页交互体验，Web 端阅读器正式落地 5 种高阶翻页动画体系：
- **覆盖 (Cover)**：底层静止，新页平铺覆盖，带边缘立体阴影。
- **滑动 (Slide)**：左右双页同频推挤滑动，严格跟手。
- **仿真 (Curl)**：3D 纸张卷角拟真翻折，呈现纸张曲面与光影。
- **滚动 (Scroll)**：无限瀑布流连续垂直滚动。
- **渐隐 (Fade)**：原地平稳交叉淡入淡出，防眩晕护眼。

配套落地了**高帧率触控跟手引擎 (Direct-DOM Pointer Engine)**，在手指/鼠标拖拽期间零 Re-render，GPU 硬件加速，支持自由拖拽停留与阈值弹性回弹。

## 3. 人工实操验收路径 (Step-by-Step)

### 测试准备
启动本地服务或 Docker 容器后打开阅读器：
1. 打开任意一本书籍进入阅读界面。
2. 点击屏幕中央呼出顶栏与底栏工具栏，点击底栏右下角「**设置 (Aa)**」打开阅读设置抽屉。

### 核验点 1：翻页动画选择器 UI
- [ ] 检查设置抽屉中是否有「**翻页动画**」网格选择项，依次包含：
  `[ 覆盖 ]  [ 滑动 ]  [ 仿真 ]  [ 滚动 ]  [ 渐隐 ]`
- [ ] 选中不同项时，下方提示语动态切换（且四语国际化正确展示）。

### 核验点 2：触控跟手拖拽与弹性回弹 (滑动 / 覆盖)
- [ ] 选择「**滑动**」：
  - 用手指（或鼠标按住）从屏幕右侧向左缓慢拖动：下一页实时紧贴着手指进入视口，上一页同频向左移出；
  - 拖动到屏幕约 15% 处松手：页面自动平滑弹性回弹，不发生翻页；
  - 拖动超过屏幕 25% 处松手：页面顺畅完成翻页并吸附至新页。
- [ ] 选择「**覆盖**」：
  - 从右向左拖动：上一页固定在底层不动，下一页带边缘渐变立体阴影覆盖上来；
  - 从左向右反向拖动：顶层页面被拉开揭起，露出底层的上一页。

### 核验点 3：3D 仿真拟真翻折 (仿真)
- [ ] 选择「**仿真**」：
  - 拖拽翻页时，页面呈现 3D 卷角折痕、背面立体反光与旋转透光效果，还原纸质书触感。

### 核验点 4：原地交叉淡入淡出 (渐隐)
- [ ] 选择「**渐隐**」：
  - 点击屏幕右侧翻页：文字无任何横向移动，当前页在 200ms 内柔和渐出，下一页平滑淡入，体验极为柔和平稳。

### 核验点 5：连续滚动 (滚动)
- [ ] 选择「**滚动**」：
  - 自动切换为垂直无限瀑布流连续阅读，向下滚动自动追加新章节。
