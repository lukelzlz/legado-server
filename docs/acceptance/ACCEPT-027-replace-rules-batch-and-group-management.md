# 验收手册 ACCEPT-027: 替换净化规则批量管理、分组管理与按钮优化 (Issue #35)

## 1. 验收背景与核心改动
针对 Issue #35 提出的「替换净化规则页面优化下图按钮，添加批量管理和分组管理」诉求，本次迭代实现了与书源管理同构的完整批量管理与可视化分组工作台：
1. **侧栏三宫格顶部入口对齐**：规则页侧栏顶部升级为标准三动作组「新建规则」、「批量管理」和「分组管理」；
2. **多选批量管理模式**：点击「批量管理」进入多选模式，左侧浮现复选框，页面底部滑出标准固底操作栏（`source-batch-bar`），支持「移动分组」、「批量启用」、「批量停用」、「导出选中」与「批量删除」；
3. **可视化规则分组管理中心 (`ReplaceRuleGroupManagerModal`)**：
   - 顶部概览展示「已有分组」、「规则总数」与「未分组规则」统计数字块；
   - 支持已有分组的**行内重命名**（同名自动合并）与**软解绑删除**（仅解绑组名，绝不误删规则）；
   - 提供**规则归类工作台**：选择或新建目标分组，在全量规则中筛选并勾选，一键加入或移出分组；
4. **详情卡片按钮视觉优化**：
   - 消除 Issue #35 中圈出的生硬无边框状态按钮；
   - 启用/停用按钮规范为统一高度（34px）与圆角（5px）的标准次级卡片（`.secondary-button.rule-toggle-btn`），启用态柔和微绿高亮，停用态中性浅底反馈，与「编辑」、「删除」构成清晰视觉秩序；
5. **全栈四语国际化 (i18n)**：全量补齐 `zh-CN`、`zh-TW`、`en-US`、`ja-JP` 词条。

## 3. 手工实操与交互验收清单 (Step-by-Step Manual Checklist)

### 验证项 1：详情卡片右上角按钮视觉反馈 (Issue #35 圈出区域)
1. 打开浏览器进入「规则」页面；
2. 选中任意一条已启用的规则：
   - 观察右上角操作按钮组：`[ 停用 ]`、`[ 编辑 ]`、`[ 删除 ]`；
   - `[ 停用 ]` 按钮此时呈现柔和微绿的高亮背景与标准 34px 高度次级卡片（`.secondary-button.rule-toggle-btn.is-enabled`），悬浮时平滑高亮；
3. 点击 `[ 停用 ]`：
   - 按钮文字秒级变为 `[ 启用 ]`，底色转为清爽的中性浅底（`.is-disabled`）；
   - 规则状态徽标同步变为灰色未启用。再次点击恢复启用。

### 验证项 2：多选与固底批量管理
1. 在侧栏顶部点击「批量管理」按钮；
2. 侧栏规则列表左侧即刻展开勾选框（复选框），页面底部平滑滑出吸底批量操作栏；
3. 点击底部批量栏的「全选」或「反选」，勾选数实时更新；
4. 测试「批量停用」与「批量启用」：所选规则的状态徽标与数据库状态瞬间批量生效；
5. 测试「导出选中」：浏览器立即触发下载所选规则的 JSON 备份；
6. 测试「移动分组」：弹出「移动到分组」弹窗，选择目标分组（或未分组），所选规则即刻批量变更归属；
7. 测试「批量删除」：弹出二次确认，确认后所选规则安全删除；
8. 点击「完成」或侧栏「退出批量」退出批量模式。

### 验证项 3：可视化分组管理中心
1. 在侧栏顶部点击「分组管理」按钮；
2. 弹出 `ReplaceRuleGroupManagerModal` 分组管理面板：
   - 查看顶部三块概览数字（已有分组、规则总数、未分组规则）；
   - 在「已有分组」列表中，点击任一分组的编辑图标，可进行**行内重命名**并回车保存；
   - 点击删除图标，提示「仅解绑组名，组内规则不会被删除」，确认后规则安全回退为未分组；
   - 在下方的「规则归类工作台」中，可选择已有分组或「＋ 新建分组…」，在下方勾选列表一键加入分组。
