# ACCEPT-034：搜索与耗时操作加载反馈

## 准备

运行 `npm --prefix web run check && npx tsx web/test/run-all.ts && ./gradlew :server:test`，并按仓库 `AGENTS.md` 的 Docker 命令启动服务；明文 HTTP 请设 `LEGADO_SECURE_COOKIES=false`。

## 实操

1. 登录后在书库输入关键词，按 Enter 搜索。预期只发起一次搜索；点击清除或按 Esc 清空并回焦；搜索中显示转圈，停止搜索按钮可用。
2. 点击搜索结果。预期**立即打开详情弹窗**，显示书名与加载动画；加载期间阅读/加入书架禁用、重复点击不触发第二次请求。数据返回后目录与操作按钮出现。
3. 请求延迟时关闭弹窗：后续响应不得重新打开；全部书源失败时可见错误，关闭后可重新点击尝试。
4. 检查换源、书源登录、网络导入、缓存清除、编辑保存等耗时按钮：转圈且不可重复提交，失败后可重试。
5. 若页面显示旧版本，先对比服务端 `/` 返回的 JS 哈希与 `web/dist/index.html`；必要时注销旧 PWA Service Worker 并刷新。

验收门禁：仅在用户明确确认后执行提交与推送。
