# ACCEPT-036 订阅源、规则订阅与一键导入 · 验收手册

对应 [`PROPOSAL-036`](../proposals/PROPOSAL-036-rss-sources-rule-subscriptions-and-online-import.md) / [`ADR-035`](../decisions/ADR-035-rss-source-as-first-class-entity-and-online-import-dispatch.md)。

## 前置

服务端需能访问外网（开发环境沙箱不通外网，以下第 3、4 步在开发阶段未实测）。

## 步骤

| # | 操作 | 预期 |
| :--- | :--- | :--- |
| 1 | 进入「订阅」页 | 有「订阅源」与「规则订阅」两个分区 |
| 2 | 订阅源分区点「导入文件」，选 `miaogongziDY.json`；或在地址框填 `http://yuedu.miaogongzi.net/shuyuan/miaogongziDY.json` 点「网络导入」并确认 | 出现「喵公子书源管理」卡片与图标；「书源」页**没有**新增名为「喵公子书源管理」的书源 |
| 3 | 点该卡片 | 内置浏览器打开 `http://yuedu.miaogongzi.net/gx.html` |
| 4 | 在页面里点任一书源导入按钮 | 弹出「导入书源」预览，勾选确认后书源入库 |
| 5 | 规则订阅分区：类型选「订阅源」，填名称与上面的 JSON 地址，勾「自动更新」填 12，保存 | 列表出现该条目，显示类型徽标、名称、「每 12 小时自动更新」 |
| 6 | 点该条目的「导入」 | 弹出确认框，显示条数与名称；确认后提示导入结果，条目的「最近更新」刷新 |
| 7 | 新建一条类型为「书源」、地址同上的订阅，点「全部更新」 | 该条显示「最近失败：订阅内容是订阅源，与订阅类型「书源」不符」 |
| 8 | 订阅源分区点「管理」，停用再启用、删除 | 状态即时变化；停用后退出管理即隐藏 |

## 开发阶段已验证

- 服务端 `RssSourceTest`（10 例，含报告者真实文件）、`SourceCodecTest` 新增 1 例。
- 前端 `subscription-page.test.ts`（6 例）。
- 真实 Chromium 端到端 18 项：真实文件导入、图标可解码、书源表保持为空、订阅字段落库、内置浏览器以 `rss::` 会话打开入口页、八种链接形态的点击拦截与类型回报、书源链接弹出预览并预填地址、不支持类型的提示、普通链接不触发导入。
