## 2. 核心功能实操验收步骤 (方案 A 极简流程)

### 用例 1：默认状态防窥保护（「全部」列表彻底排除与计数防端倪）
1. 访问 `https://review-ui.connectluke.eu.org`，输入密码 `admin123456` 登录并进入书架。
2. 观察默认停留在「全部」Tab 时的书架列表与顶部标签栏。
3. **预期表现**：
   - 顶部 Tab 栏只显示公开分组：**全部 (7)**、**未分组 (2)**、**仙侠修真 (3)**、**科幻未来 (2)**；
   - **顶栏保持极简，无多余的展开按钮，「私密藏书」分组 Tab 完全不展示**；
   - 书架「全部」列表中仅展示 7 本公开/未分组书籍，**《大奉打更人》、《剑来》、《雪中悍刀行》彻底被排除，封面和书名完全无痕**；
   - 切换下方的「正在阅读」、「已读完」胶囊过滤，统计数字同样严格基于可见书籍，杜绝数字端倪。

---

### 用例 2：分组管理中恢复公开显示
1. 点击分组 Tab 栏右侧的 **「⚙️ 管理分组」** 按钮，打开「书架分组管理」弹窗。
2. 观察分组列表中每个分组：
   - 「私密藏书」分组名称旁边带有 **🔒** 徽标，右侧眼睛按钮高亮激活（提示“恢复公开显示”）。
3. 点击「私密藏书」右侧的眼睛按钮。
4. **预期表现**：
   - 弹出提示 `已将分组「私密藏书」恢复为公开`；
   - 关闭分组管理弹窗后，书架顶部 Tab 栏立即出现 **「私密藏书 (3)」** 分组，书架总数同步恢复为 **全部 (10)**；
   - 点击「私密藏书」Tab，可正常浏览与阅读组内 3 本书籍（《大奉打更人》、《剑来》、《雪中悍刀行》）。

---

### 用例 3：分组管理中将分组设为隐藏
1. 再次点击 **「⚙️ 管理分组」** 打开弹窗。
2. 找到任意公开分组（例如「科幻未来」或「私密藏书」），点击其右侧的眼睛按钮。
3. **预期表现**：
   - 弹出提示 `已将分组「...」设为隐藏`；
   - 关闭弹窗后，该分组的 Tab 立即从书架顶栏移除，且该分组内的所有书籍从「全部」列表中被完全排除，总数自动扣减；
   - 若之前恰好停留在该分组上，系统自动安全退回「全部」视图。

## 3. 回归与异常检查项 (Sanity & Edge Checks)

- [ ] **多语言适配**：切换系统语言为英文、繁体中文或日文，分组管理中眼睛按钮提示文案均正确翻译展示。
- [ ] **刷新与持久化**：在分组管理中设为隐藏或恢复公开后，刷新浏览器，状态稳定保持。
- [ ] **Legado 备份协议对齐**：导出 `bookGroup.json` 时，隐藏分组为 `"show": false, "isPrivate": true`，公开分组为 `"show": true, "isPrivate": false`。
