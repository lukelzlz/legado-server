## 2. 功能测试核验清单

### 2.1 听书启动与悬浮控制条
1. 打开任意一本书籍进入阅读器。
2. 点击顶部导航栏或移动端底部的“听书/朗读”按钮。
3. **预期效果**：
   - 底部滑入毛玻璃悬浮胶囊控制条（`TtsPlayerBar`）。
   - 开始朗读章节标题，并进入第一段。
   - 当前正在朗读的段落出现淡绿色光晕背景与左侧高亮标识（`.tts-active-paragraph`）。
   - 正在发音的句子呈现重点文本高亮（`.tts-active-sentence`）。

### 2.2 视口跟随与点击段落跳转
1. 点击控制条上的“下一句”或等待朗读进行。
2. **预期效果**：随着朗读进行，阅读界面平滑自动滚动，始终保持正在朗读的句子位于屏幕舒适视野中心。
3. 点击阅读区域内任意其他段落。
4. **预期效果**：朗读光标立即跳转到点击的段落并即刻发音。

### 2.3 调音设置与音色切换
1. 点击悬浮控制条上的设置图标（或控制条左侧文本区域），展开调音面板。
2. 切换引擎至“微软 Edge-TTS”，发音人选择“云希 (男声·沉稳磁性)”或“晓晓 (女声·温暖自然)”。
3. 调节语速至 1.25x，语调至 1.05。
4. **预期效果**：发音人与语速即刻切换为微软高清神经网络音色，声音自然细腻。

### 2.4 睡眠定时器与跨章连播
1. 在调音面板中选择睡眠定时为“读完本章”或“15 分钟”。
2. **预期效果**：控制条上显示对应的倒计时标签；倒计时结束或本章读完后自动优雅停止并弹出 Toast 提示。
3. 开启“读完本章自动连播下一章”并让当前章读完。
4. **预期效果**：章节末尾自动平滑翻页至下一章并从新章节第 0 句继续朗读。
