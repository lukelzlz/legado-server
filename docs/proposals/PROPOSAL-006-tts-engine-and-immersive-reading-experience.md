# PROPOSAL-006: 现代化 TTS 朗读引擎与沉浸式听书体验

## 1. 业务背景与问题痛点

在当前的 Web 阅读器中，朗读功能仅通过 `window.speechSynthesis.speak(new SpeechSynthesisUtterance(...))` 粗暴地将整章文本一次性丢给浏览器：
1. **无分片与高亮**：无法在正文中看到当前正在朗读哪一段、哪一句，无法点击正文段落定位朗读。
2. **缺乏视口跟随**：朗读过程中页面静止，不会随朗读进度自动平滑滚动或翻页。
3. **无法跨章连续听书**：当前章节读完后朗读直接终止，无法自动跳转并继续朗读下一章。
4. **引擎单一且受限**：仅依赖浏览器本地系统音色，缺乏发音人切换、语速/语调调节；无法使用如 Legado 原版的高音质在线 TTS（如微软 Edge 极高拟真音色、自定义 HTTP TTS 引擎）。
5. **缺少听书辅助能力**：缺乏悬浮播放控制条（上一句/下一句/进度调节）、睡眠定时器（定时停止/读完本章停止）、特殊符号/作者杂音文本净化、以及锁屏/耳机后台控制 (MediaSession)。

## 2. 目标与非目标 (Goals & Non-Goals)

### Goals (目标)
1. **双引擎架构 (Web Speech + HTTP 在线 TTS)**：
   - 本地引擎：Web Speech API 深度优化（智能句子分块、枚举系统音色、语速/语调精细调节）。
   - 在线引擎：支持类似 Legado 的 HTTP/在线 TTS 引擎规范（预置微软 Edge-TTS 超自然高音质音色，支持导入/配置自定义 HTTP TTS 源），服务端提供安全代理中继与流式音频输出，消除跨域与网络阻碍。
2. **段落/句子级切分与正文高亮联动**：
   - 将章节内容智能切分为段落与句子单元；
   - 朗读时在正文区实时醒目高亮当前段落与当前句子；
   - 阅读器视口自动平滑滚动以保持当前朗读焦点居中（分页模式下自动翻页）。
   - 支持**点击正文任意段落**直接从该段落开始朗读。
3. **无缝跨章连播**：
   - 章节读完最后一句后，自动保存当前进度并无缝切换至下一章继续朗读；
   - 联动后台离线预加载，确保切章零卡顿。
4. **沉浸式播放控制与调音面板**：
   - 底部常驻悬浮播放控制条：播放/暂停、上一句/下一句、上一章/下一章、段落进度拖拽、展开高级设置；
   - 调音面板：引擎切换、发音人 Voice 切换、语速（0.5x ~ 3.0x）、语调（Pitch 0.5 ~ 1.5）；
   - 睡眠定时器：15/30/45/60分钟倒计时、读完本章后停止、读完当前段落后停止；
   - 文本过滤净化：自动过滤连续分隔符、多余空白与无意义特殊符号，支持自定义净化规则。
5. **现代 Web 媒体与锁屏联动**：
   - 接入 `navigator.mediaSession`（锁屏与通知栏展示书名、章节名、作者与封面，响应耳机线控按键）；
   - 接入 `navigator.wakeLock`（听书期间防止移动端自动熄屏中断播放）。

### Non-Goals (非目标)
1. 本次迭代不引入重量级的第三方大型客户端音频解码库（如 ffmpeg.wasm），优先使用浏览器原生 Web Audio / HTML5 Audio 及 Web Speech API。
2. 不修改书架或书源数据库核心结构（HTTP TTS 引擎数据独立管理）。

## 3. 核心用户故事 (User Stories)

### Story 1: 沉浸式听书与高亮视口跟随
- **场景**：作为读者，点击顶部工具栏的“朗读”按钮进入听书模式。
- **行为**：
  1. 底部弹出精致的悬浮听书控制栏，当前正在朗读的段落与句子出现呼吸/高亮背景；
  2. 随着朗读推进，正文视口平滑滚动，焦点始终处于视线舒适区；
  3. 读者点击第 5 段，朗读立即定位并无缝从第 5 段开始发声。

### Story 2: 跨章自动连播与睡眠定时
- **场景**：作为睡前听书的读者，希望连续听多章且在设定时间后自动停止。
- **行为**：
  1. 读者在悬浮面板中打开睡眠定时器，选择“30分钟后关闭”或“读完本章后停止”；
  2. 读完当前章最后一句后，阅读器自动翻到下一章并继续流畅朗读；
  3. 达到设定时间或本章结束时，朗读平滑停止并自动持久化保存最新的阅读进度。

### Story 3: 切换高音质在线发音人 (Edge TTS) 与语速调节
- **场景**：作为对音质有要求的读者，希望使用逼真的 AI 语音（如微软晓晓、云希）。
- **行为**：
  1. 读者在调音面板中选择“微软 Edge TTS”引擎，发音人选择“zh-CN-YunxiNeural（云希）”，语速调整为 1.25x；
  2. 系统通过服务端代理快速预缓冲下一句音频分片，以极低延迟无缝播放高拟真语音。

### Story 4: 锁屏与耳机按键后台控制
- **场景**：作为移动端读者，开启听书后将手机装入口袋或锁屏。
- **行为**：
  1. 手机锁屏界面和通知栏显示《书名》、当前章节名及封面；
  2. 双击耳机线控或锁屏“下一曲”按钮，自动跳到下一段继续朗读；
  3. 点击暂停/继续，系统正确响应并同步更新阅读进度。

## 4. 验收基准 (Acceptance Criteria)

- [ ] **分片与高亮**：正文段落与句子实时高亮渲染准确，点击段落准确定位并从该位置开始朗读。
- [ ] **视口跟随**：滚动模式下视口平滑居中跟随，分页模式下换页准确。
- [ ] **跨章连播**：最后一章读完自动拉取下一章正文并连贯播放，进度正确落盘。
- [ ] **双引擎支持**：Web Speech 引擎本地零依赖秒起；HTTP TTS / Edge TTS 服务端代理音频流稳定无杂音，分片音频预缓冲无缝衔接。
- [ ] **播放控制与定时器**：悬浮条与控制面板交互流畅，定时器倒计时准确停止。
- [ ] **自动化测试**：通过全量前端检查（`npm --prefix web run check`、`npx tsx web/test/run-all.ts`）与后端单元测试（`./gradlew :server:test`）。
