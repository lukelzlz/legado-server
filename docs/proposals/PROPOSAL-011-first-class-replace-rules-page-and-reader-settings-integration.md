# PROPOSAL-011: 替换净化规则升级为一级独立页面与阅读器设置抽屉集成

## 1. 业务背景与问题痛点
- 替换净化规则原本以弹窗（Modal）形式实现，入口隐藏在全局右上角汉堡菜单（`≡`）与阅读器顶栏中。
- 用户反馈不易发现且操作受限；替换规则作为与“书源”、“订阅”同等重要的核心治理模块，应当具备独立的一级页面（Page）展示与管理体验。
- 阅读器顶栏图标过多导致视觉分散，用户期望将阅读器内的净化规则配置统一收敛至已有的「阅读设置」抽屉中。

---

## 2. 目标与非目标 (Goals & Non-Goals)

### Goals
1. **升级为顶级独立页面**：
   - 顶部主导航栏（`AppHeader`）新增 `[规则]`（或 `[替换净化]`）一级 Tab，与 `[书库]`、`[书架]`、`[书源]`、`[订阅]` 并列展示。
   - 实现全屏的独立页面 `ReplaceRulesPage`，提供双栏式/宽屏友好的规则列表、分组筛选、搜索过滤、快速启停、批量操作、订阅导入/导出与即时沙箱测试面板。
2. **阅读器设置抽屉收敛集成**：
   - 从阅读器顶栏移除独立的「替换净化」图标按钮，保持顶栏清爽。
   - 在右侧「阅读设置」抽屉（Settings Drawer）中新增「替换净化」功能卡片/入口，支持直接查看与配置当前书籍生效的专用规则，保存后即时无缝重刷正文。
3. **平滑导航与状态联动**：
   - 支持从全局导航栏、右上角菜单及阅读器设置无缝跳转/呼出。

### Non-Goals
- 不修改后端已落地的 RESTful API、Rhino 沙箱执行管道与 SQLite 数据表结构（完全沿用 PROPOSAL-010 / ADR-010 已验证的基础设施）。

---

## 3. 核心用户故事 (User Stories)

- **Story 1（主导航直达独立规则管理页）**：
  - *场景*：用户打开网页端，在顶部主导航栏直观看到 `[书库]` `[书架]` `[书源]` `[订阅]` `[规则]`。
  - *行为*：点击 `[规则]` 标签，直接切换到全屏的「替换净化规则」管理页面，左侧为规则列表与分组检索，右侧为规则编辑、订阅导入/导出与沙箱实时调试。
  
- **Story 2（阅读设置抽屉内快捷管理与当前书专用）**：
  - *场景*：用户在阅读《宅魔女》时发现有错字反爬。
  - *行为*：点击顶栏「阅读设置」按钮（齿轮图标），在弹出的设置抽屉中看到「替换净化」选项区，点击可快速编辑当前书专用规则或跳转规则中心，保存后当前章节内容立即重新清洗刷新。

- **Story 3（移动端自适应响应）**：
  - *场景*：移动端屏幕较窄时。
  - *行为*：导航栏与规则页面自适应折叠排版，操作流程依然顺畅自然。

---

## 4. 验收基准 (Acceptance Criteria)
- [ ] 顶部导航栏拥有独立的 `规则` 页面入口，点击可流畅切换路由并高亮。
- [ ] `ReplaceRulesPage` 具备独立全屏 UI，完整支持搜索、分组筛选、新增、编辑、删除、批量操作、订阅导入与沙箱测试。
- [ ] 阅读器顶栏移除冗余按钮，阅读设置抽屉内成功集成替换规则入口与当前书专用配置。
- [ ] 前端类型检查与自动化测试通过：`npm --prefix web run check && npx tsx web/test/run-all.ts`。
