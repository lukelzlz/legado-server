# PROPOSAL-013: 移动端全面屏死区安全区深度适配与替换净化规则 UI 体系化重构

## 1. 业务背景与问题痛点

1. **全面屏死区遮挡严重**：
   - 在 iPhone（刘海屏 / 灵动岛 Dynamic Island）及主流全面屏 Android 机型上，阅读器顶栏被系统状态栏与时间/电量图标严重覆盖，无法清晰识别书籍标题与返回键。
   - 阅读器底栏控制条（目录、换源、朗读、设置）紧贴屏幕下边缘，与系统手势指示条（Home Indicator）发生触控与视觉冲突。
   - 连续滚动模式和分页阅读模式未预留足够安全内边距，导致正文首行文字与刘海重叠，翻页视口边缘切断。
   - 全局顶栏（`app-page-header`）的 CSS `padding:` 简写覆盖了 `padding-top: var(--safe-top)`，导致移动端主导航栏同样贴死状态栏。
2. **替换净化规则页面 UI 风格割裂**：
   - 当前 `ReplaceRulesPage.tsx` 充斥大量硬编码深色内联样式（`color: #fff`, `background: rgba(255,255,255,0.06)`, `background: #4f46e5` 等），在浅色模式（`theme-light`）和纸质模式（`theme-paper`）下文字与背景混成一体无法阅读。
   - 规则列表与编辑/测试区域在移动端未做响应式卡片流折叠处理，手机端排版杂乱拥挤。
   - 缺少与书架、书源、订阅管理一致的设计系统色彩令牌（`var(--surface)`, `var(--ink)`, `var(--accent)` 等）与交互反馈。

---

## 2. 目标与非目标 (Goals & Non-Goals)

### Goals
1. **全局全面屏安全区深度渗透**：
   - 修复全局 `app-page-header`、阅读器顶栏 `reader-header`、移动端底栏 `mobile-reader-nav` 的 safe-area 内边距，并在 `@media (max-width: 720px)` 等断点中严格保留，杜绝高度写死覆盖。
   - 阅读器正文滚动模式（Scroll）与分页模式（Paginated）全面考虑 `var(--safe-top)` 与 `var(--safe-bottom)`，正文首行、末行与翻页控制区始终处于物理安全可视区域。
   - 目录抽屉（TOC）、阅读设置抽屉、各页面模态对话框底部增加安全区避让，适配全面屏底部 Home 虚拟手势条。
2. **替换净化规则页面 UI 体系化美化与重构**：
   - 彻底剥离硬编码内联样式，统一抽取并接入主题系统 CSS 变量，全面支持 Light、Paper、Dark 三种阅读主题自适应。
   - 移动端（窄屏）采用优雅的上下流式卡片堆叠展开（折叠面板）交互，展开单条规则即可快捷就地测试沙箱与编辑。
   - 统一分组筛选胶囊、规则状态 Switch 开关、正则/JS 标识徽章、新建/编辑/导入弹窗的视觉语言，与书源、订阅页面风格完全统一。

### Non-Goals
- 不修改后端替换净化规则的执行沙箱内核（Rhino / Regex 替换管道）。
- 不调整服务端已有的替换规则 API 数据协议结构。

---

## 3. 核心用户故事 (User Stories)

- **Story 1（全面屏沉浸阅读避让）**：作为移动端（iPhone / Android 全面屏）用户，打开任意小说阅读时，顶栏清晰显示在灵动岛/刘海下方，正文首行不被时间电量遮挡；底部快捷栏（目录、换源、朗读、设置）位于手势条上方，点击精准不误触。
- **Story 2（分页与滚动双模式安全区）**：作为读者，在切换「平移分页」或「连续滚动」模式时，整页文字始终位于屏幕安全可视范围内，章节标题与页码信息清晰可见。
- **Story 3（规则管理多主题无缝适配）**：作为切换了「浅色（Light）」或「羊皮纸（Paper）」主题的用户，进入「替换净化规则」页面时，页面背景、文字、标签与卡片高亮均清晰美观，不再出现白底白字或刺眼深色色块。
- **Story 4（手机端流式卡片与沙箱调试）**：作为手机用户在规则页面浏览时，可以通过优雅的分组胶囊快速筛选，点击规则卡片即时展开查看模式详情、运行测试沙箱或切换启用/停用，操作流畅直观。

## 4. 验收基准 (Acceptance Criteria)

- [ ] **安全区验证**：在移动端视口（含模拟带有 Safe Area Insets 的浏览器环境）中，全局顶栏、阅读器顶栏、阅读器底栏、抽屉底部均正常避让死区。
- [ ] **排版验证**：滚动模式首行不与刘海重叠；分页模式上下留白符合安全区，内容翻页不截断。
- [ ] **主题一致性验证**：在 Light、Paper、Dark 三种主题下切换，替换规则页面的背景、字体、按钮、输入框、代码块、状态徽章均正常呈现。
- [ ] **响应式验证**：窄屏（<720px）下规则页面呈现卡片堆叠折叠交互；宽屏下保持高密度专业管理布局。
- [ ] **自动化测试与构建**：`npm --prefix web run check` 与 `npx tsx web/test/run-all.ts` 100% 通过。
