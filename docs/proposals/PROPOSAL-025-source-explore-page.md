# PROPOSAL-025: 书源发现页（Explore）与多维分类浏览体系 (Issue #24)

## 1. 业务背景与问题痛点
当前 Legado Server 与 Web 客户端已经具备完善的书架、全源搜索、书源管理、替换净化、本地图书与 WebDAV 能力。然而，在小说阅读的核心用户链路中，仍存在一个重大缺失：
1. **缺乏书源“发现”能力**：开源阅读 Android 平台中，“发现页”是用户最核心的寻书入口之一。用户在没有明确书名或作者目标时，依赖发现页浏览各个书源的精品排行榜、分类榜单、完结推荐、新书速递等栏目。
2. **书源自带发现能力闲置**：现有导入的大量 Legado 书源中均包含配置好的 `exploreUrl`（多行标签、分类树或 `<js>` 动态生成）和 `ruleExplore`（发现规则），但在无头服务端和 Web 端一直未被激活利用。
3. **用户无法直接从发现流加入书架**：用户无法直接在推荐列表中浏览小说简介、封面、分类，并一键完成“加入书架”或“立即开读”，严重削弱了 Web 端的沉浸式看书体验。

## 2. 目标与非目标 (Goals & Non-Goals)

### Goals
- **顶栏一级导航增设「发现」选项卡**：在主导航栏新增「发现」（Explore）入口（`type Page = ... | 'explore'`），支持在书架、书库、发现之间无缝切换。
- **书源与发现分类解析引擎 (RuleRunner)**：
  - **书源过滤**：支持获取所有配置了 `exploreUrl` 的可用书源列表，并支持按书源名称、分组进行快速过滤与切换。
  - **`exploreUrl` 全语法兼容**：
    - 支持 `<js>...</js>` 与 `@js:...` 沙箱脚本求值；
    - 支持 JSON 数组与树形分类解析（如 `[{"title": "榜单", "url": "..."}]`）；
    - 支持 Legado 经典多行纯文本语法（`标题::URL`、`标题&&URL` 以及带缩进的层级分组）。
  - **`ruleExplore` 智能解析与规则继承回退**：
    - 优先采用 `ruleExplore`（`bookList`, `name`, `author`, `intro`, `coverUrl`, `bookUrl`, `kind` 等）；
    - 若书源未配置 `ruleExplore` 或 `ruleExplore.bookList` 为空，**自动无感回退至 `ruleSearch`**（完全契合 Legado 生态隐性契约）。
- **发现书籍列表流式浏览与分页**：
  - 分类请求支持 `{{page}}` 宏变量替换，支持 `url,{options}` 拆解与书源 Cookie/Header 合并请求；
  - 提供分页或“加载更多”机制，平滑加载后续批次书籍。
- **现代化 Web 发现页面交互**：
  - **分类导航区**：左侧/顶部展示书源切换器与当前书源的分类/榜单标签（支持多层级分类折叠与切换）；
  - **书籍卡片流**：展示书籍封面、书名、作者、标签/状态、简介摘要；
  - **便捷开读与加架**：提供“加入书架”（带已在书架状态指示与防重提示）与“立即开读”秒开入口。
- **全栈国际化**：四语基准（`zh-CN`, `zh-TW`, `en-US`, `ja-JP`）词典全面覆盖。

### Non-Goals
- 不在后台定时爬取、扫描或持久化全网书源的发现页数据；遵循“按需请求、实时解析”原则，杜绝无节制打满上游服务器。
- 不修改底层书源数据表的存储 Schema（沿用 `source` 表的 payload 存储）。
- 不对 Android 原生的专有百分比 UI 布局属性（`layout_flexGrow` 等）进行像素级重现，统一映射为现代 Web 响应式 Grid/Flex 胶囊卡片与标签布局。

## 3. 核心用户故事 (User Stories)

- **Story 1（发现入口与书源发现栏目展示）**：
  作为读者，我在顶栏点击「发现」选项卡，页面列出已配置发现页的书源。选中某个书源（如“笔趣阁”或“聚合源”），系统在左侧（或顶部）清晰展示该书源提供的分类与榜单栏目（如“周热榜”、“月票榜”、“玄幻奇幻”、“都市言情”等）。
- **Story 2（点击栏目加载书籍与流式翻页）**：
  作为读者，我点击“月票榜”，主视口即刻展示该栏目的书籍列表，包含封面缩略图、书名、作者、类型标签及简介摘要。当滚动到底部时，点击或触发“加载更多”，系统以 `page=2` 顺畅获取第二页并自动拼接到列表下方。
- **Story 3（一键加入书架与即刻开读）**：
  在发现列表中发现一本感兴趣的书籍，点击“加入书架”，后端异步补全并写入书架，按钮变为“已在书架”；若点击“立即阅读”，直接秒开阅读器进入该书的第一章开始沉浸式阅读。
- **Story 4（兼容复杂书源与规则回退）**：
  对于只配置了 `ruleSearch` 而未写 `ruleExplore` 的海量民间书源，或者 `exploreUrl` 依赖 `<js>` 动态计算登录凭据的书源，系统在沙箱内正确求值并回退解析，不会报错白屏。

## 4. 验收基准 (Acceptance Criteria)

- [ ] 服务端单元测试覆盖 `exploreUrl`（多行文本、`::`/`&&` 分隔、JSON 结构、`<js>` 脚本求值）以及 `exploreBooks`（含 `ruleExplore` 与 `ruleSearch` 回退）。
- [ ] 前端类型检查与自动化测试全绿（`npm --prefix web run check` 与 `npx tsx web/test/run-all.ts`）。
- [ ] 顶栏清晰展示「发现」选项卡，支持四国语言无缝切换。
- [ ] 发现页能够正常列出支持发现的书源，切换书源后正确展示分类。
- [ ] 点击分类能够加载书籍列表，支持分页加载更多。
- [ ] 列表中的书籍支持一键加入书架并提示状态，支持直接跳转阅读。
