# PROPOSAL-027: 阅读器全量翻页动画体系与高帧率触控跟手引擎 (覆盖/滑动/仿真/滚动/渐隐)

## 1. 业务背景与问题痛点
当前 Web 客户端（`ReaderScreen.tsx`）的阅读模式仅有简单的“连续滚动 (`scroll`)”与“平移分页 (`paginate`)”。
在分页模式下，页面切换依赖简单的 CSS `translateX` 或生硬的 DOM 切页，缺乏现代移动阅读器与原生 Legado App 标配的高阶视觉体验：
1. **动画类型缺失**：缺少 Legado 经典的高级翻页效果——**覆盖 (Cover)**、**滑动 (Slide)**、**仿真 (Curl / 3D 拟真卷页)**、**滚动 (Scroll)** 及 **渐隐 (Fade)**。
2. **缺乏触控跟手性 (Touch-Tracking / Drag-to-Turn)**：在手机/触屏端轻扫翻页时，页面无法跟随手指实时拖拽拉出、无法在拖到一半时停留、也无法根据手势拖拽位移与释放初速度智能决定翻页或弹性回弹。
3. **设置项割裂**：阅读设置抽屉仅提供生硬的单选项，与 Legado 原生设置面板的直观视觉矩阵存在代差。

## 2. 目标与非目标 (Goals & Non-Goals)

### 核心目标 (Goals)
1. **5 种翻页动画全量支持**：
   - **覆盖 (Cover)**：底页静止，新页自右侧（或左侧）平滑滑入覆盖，带有物理边缘渐变阴影。
   - **滑动 (Slide / Push)**：双页联动推挤滑动，当前页滑出与新页滑入同频推进。
   - **仿真 (Curl / 3D Page Flip)**：拟真翻书卷角与弯曲阴影，模拟纸张折叠与背面微透光光影效果。
   - **滚动 (Scroll)**：无缝继承已上线的 PROPOSAL-026 瀑布流虚拟窗口连续滚动。
   - **渐隐 (Fade)**：原地交叉淡入淡出（Crossfade），零横向晃动，极致柔和护眼。
2. **高帧率触控跟手引擎 (Touch-Tracking Interaction Engine)**：
   - 采用标准 `PointerEvents` 统一捕获 Touch / Mouse 拖拽。
   - 支持实时手指跟随（Follow-through dragging）：手指位移实时驱动页面呈现相应动画进度（0% ~ 100%）。
   - 惯性与阈值自适应：滑动超过屏幕宽度的 25% 或瞬时速度超过 0.5px/ms 自动翻页，否则执行 Spring 曲线平滑回弹。
   - 保持 60~120 FPS 高帧率渲染，避免任何重排（reflow），全量使用 CSS 3D Transforms / Canvas 硬件加速。
3. **UI 与国际化无缝对齐**：
   - 阅读设置抽屉新增「**翻页动画**」网格选择器：`[ 覆盖 ] [ 滑动 ] [ 仿真 ] [ 滚动 ] [ 渐隐 ]`。
   - 补充 `en-US`, `zh-TW`, `zh-CN`, `ja-JP` 四语国际化字典。
   - 跨端设置持久化至 `localStorage`。

### 非目标 (Non-Goals)
- 本次不改动服务端的正文提取与目录解析逻辑。
- 仿真翻页在桌面端仅通过鼠标拖拽或边缘点击驱动，不针对触控笔压感做特殊物理形变。

## 3. 核心用户故事 (User Stories)

### Story 1: 触屏跟手拖拽翻页（以“覆盖”与“滑动”为例）
- **作为** 手机端 Web/PWA 用户，
- **当** 我用手指从屏幕右边缘向左拖动时，
- **系统** 实时跟随我的手指将下一页拉入视口：
  - 若当前模式为“覆盖”，上一页原地不动，下一页带着左侧投影覆盖上来；
  - 若为“滑动”，上一页随手指同步向左移出，下一页无缝贴合进入；
- **当** 我拖动到屏幕 40% 处松开手指时，
- **系统** 平滑执行加速补间动画完成翻页并落定；若我只拖动了 10% 并退回松开，系统优雅回弹复原。

### Story 2: 沉浸式 3D 仿真翻页 (Curl)
- **作为** 热爱拟真纸质书阅读感的用户，
- **当** 我在设置中选择“仿真”并从屏幕边缘拖动时，
- **系统** 呈现拟真的卷角翻页动画，书页展现自然的弧度弯曲、内侧阴影与翻动折痕，并在翻过中线后顺滑展开，完全还原实体书翻阅质感。

### Story 3: 极简防眩晕渐隐翻页 (Fade)
- **作为** 夜间阅读或易晕动症用户，
- **当** 我选择“渐隐”并点击屏幕右侧翻页时，
- **系统** 不做任何横向移动，当前页文字在 200ms 内柔和渐出，新一页文字同频淡入，视觉平稳护眼。

### Story 4: 翻页动画快速切换与状态持久化
- **作为** 读者，
- **当** 我在阅读器设置中切换“覆盖 / 滑动 / 仿真 / 滚动 / 渐隐”任一选项时，
- **系统** 立即应用该交互，且重新打开阅读器或刷新页面后偏好依然生效。

## 4. 验收基准 (Acceptance Criteria)
- [ ] 5 种动画模式（覆盖、滑动、仿真、滚动、渐隐）在设置面板中均可正常点选切换。
- [ ] 分页类动画（覆盖、滑动、仿真、渐隐）在触控/鼠标轻扫时具备细腻跟手拖拽与阈值回弹。
- [ ] 翻到章节末尾与开头时，跨章翻页能无缝衔接正文并正确定位。
- [ ] 多语言支持（中、繁、英、日）完整。
- [ ] 前端测试套件全绿，零回归。
