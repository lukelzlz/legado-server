# PROPOSAL-027: 替换净化规则批量管理、分组管理与操作按钮视觉体系化重构 (Issue #35)

## 1. 业务背景与问题痛点
在开源阅读生态中，用户通常会导入海量净化规则（数十至数百条）以过滤反爬乱码、防盗章节与广告引流。然而当前 `ReplaceRulesPage` 存在明显体验瓶颈：
1. **缺少多选批量管理**：仅有顶栏粗粒度的「全部启用/全部禁用」，无法对筛选或任意选中的部分规则进行批量启用、停用、改组、导出或彻底删除。
2. **缺少体系化分组管理**：当前分组仅作为单向展示标签，缺乏像书源管理面板那样直观的“分组改名、分组解绑删除、规则批量归类”工作台。
3. **详情卡片按钮视觉失衡**（Issue #35 截图圈出）：详情卡片右上角的「停用/启用」按钮为无状态感知的 `.ghost-button`，与其他按钮视觉层级混乱、样式脱节。

## 2. 目标与非目标 (Goals & Non-Goals)
- **Goals**：
  - **批量管理模式**：对齐书源页与书架页设计，支持列表多选、全选/反选与固底操作栏（批量启用、禁用、移动分组、导出、删除）。
  - **可视化分组管理中心**：引入 `ReplaceRuleGroupManagerModal`，提供概览数字块、已有分组列表（重命名/删除解绑）与规则批量归类工作台。
  - **按钮视觉与详情区重构**：规范详情卡片按钮为统一基类（高度 34px、圆角 5px、具备清晰的状态与危险警示层级）。
  - **全栈 API 支持**：后端扩展 `/api/replace-rules/batch`（支持 action: enable, disable, set_group, delete）与分组改名/解绑端点。
  - **全栈四语国际化 (i18n)**：中/繁/英/日 100% 词条补全。
- **Non-Goals**：
  - 不修改正文净化沙箱核心执行引擎。
  - 不引入独立的分组持久化表（复用 `replace_rule.group` 字符串列，遵循 nocase 归一化）。

## 3. 核心用户故事 (User Stories)
- **Story 1（批量管理）**：作为用户，在替换净化规则页面，点击侧栏顶部的「批量管理」按钮，进入多选批量模式。列表展现复选框，底部滑出固底操作栏，可快速批量启用、停用、导出、移动分组或删除。
- **Story 2（分组管理面板）**：作为用户，点击侧栏「分组管理」按钮，打开分组工作台。可重命名分组、解绑删除分组，或在归类卡片中批量勾选规则加入/移出指定分组。
- **Story 3（操作按钮体验优化）**：作为用户，在规则详情卡片中，启用/停用按钮具备清晰的状态视觉反馈与标准次级按钮基类，与编辑、删除形成统一、高质感的视觉秩序。
