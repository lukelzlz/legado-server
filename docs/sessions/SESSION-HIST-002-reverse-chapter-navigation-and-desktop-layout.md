# 历史推演归档：阅读器跨章反向翻页定位与桌面端双栏/宽屏排版

## 1. 历史问题现象与排查背景
- **问题现象 1**：在阅读器中从当前章节的第 1 页往回翻页（或向上滚动）切换到上一章时，页面默认滚到了上一章的最顶端（第 1 页），而非上一章的最后一页/末尾，打断了逆向连续阅读流程。
- **问题现象 2**：在桌面端大屏幕（如 2K/4K 显示器）下，阅读器内容被单列撑满或固定在窄手机比例，缺乏双栏翻页与版心自适应调节。

## 2. 曾尝试的无效路径与失败原因
1. **无效路径 1：简单在切换章节后通过 `window.scrollTo(0, document.body.scrollHeight)` 触底**
   - *失败原因*：正文内容是异步渲染与分栏计算的，在 DOM 尚未完成分页测算（`columns` / `virtualPages`）前执行滚动定位，导致高度计算失真，定位回弹或停留在中间位置。
2. **无效路径 2：仅对上一章做正文拉取而不维护定位状态标记**
   - *失败原因*：组件重绘与分页更新会重置当前页码 `currentPage` 为 0，丢失了“用户是从下一章回翻进来的”意图。

## 3. 最终落地的解决策略
1. **明确目标定位状态机（`targetPosition: 'bottom' | 'top'`）**：
   - 当触发“上一章”逆向翻页时，将状态标记为 `targetPosition = 'bottom'`。
   - 正文完成加载与分页计算后，根据阅读模式执行精准锚定：
     - **分栏/翻页模式**：自动计算总页数并跳转到最后一页（`totalPages - 1`）。
     - **垂直滚动模式**：通过 `requestAnimationFrame` 配合容器滚动高度将 `scrollTop` 精准定位于容器底部。
2. **上一章正文反向预加载（Reverse Preload Guard）**：
   - 增加反向预加载机制，防止回翻时出现白屏或加载闪烁。
3. **桌面端双栏与宽屏自适应重构**：
   - 支持单栏/双栏自适应切换、版心宽度调节与侧边栏常驻钉选。

## 4. 沉淀至部落知识库的经验条目
- **[翻页] 逆向切章定位**：跨章逆向切章必须携带 `targetPosition = 'bottom'` 标记，并在分页/排版渲染完成后再执行定位跳转。
- **[排版] 异步渲染高度守卫**：禁止在 DOM 异步排版未完成前计算滚动位置，必须通过完成度回调或 `useEffect` 守卫触发锚定。
